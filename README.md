# Mission Analyzer

**Аналіз місій ArduPilot / Mission Planner** — десктоп-застосунок на
Python/Tkinter для перевірки маршрутів `.waypoints` перед польотом:
запас висоти над рельєфом (SRTM), гострі повороти, кут набору/зниження,
глісада заходу на посадку, погода в точках старту й посадки, пряме
підключення до ArduPilot по MAVLink.

> A desktop mission-analysis tool for ArduPilot/Mission Planner
> `.waypoints` files — terrain clearance, turn/climb angle checks,
> landing glide-slope profile, weather at takeoff/landing, and direct
> MAVLink connect to read/write missions from the flight controller.
> ![Mission Analyzer](mission-analyzer-main.png)

## Можливості

- Розбір `.waypoints` (QGC WPL 110), повна таблиця команд місії
- Перевірки: запас висоти над рельєфом (SRTM), гострі повороти, кут
  траєкторії поза допуском
- Профіль висоти, профіль кута траєкторії, профіль глісади заходу на
  посадку з рельєфом
- Карта маршруту (OSM/Google, офлайн-кеш тайлів) + окремі квадратні
  карти 4×4 км навколо точок старту й посадки
- Погода в точках старту/посадки (Open-Meteo, безкоштовно): вітер,
  температура, схід/захід сонця, оцінка бокового/зустрічного вітру на
  зліт і посадку
- Прямий зв'язок з ArduPilot по MAVLink: читання й запис місії на борт
- Експорт звіту аналізу в PDF
- Українська та англійська локалізація

## Встановлення

Потрібен Python 3.10+.

```bash
pip install reportlab pyserial pymavlink Pillow
python app.py
```

`reportlab` потрібен для експорту в PDF, `pyserial`/`pymavlink` — для
підключення до ArduPilot, `Pillow` — для JPEG-тайлів супутникових карт
і якісного масштабування логотипу. Без них застосунок все одно
запускається, просто відповідні функції обмежені (детальніше в
[`ARCHITECTURE.md`](./ARCHITECTURE.md)).
